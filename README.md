# nightra-slack-digest

ナイトラ（NICE TRY CLUB）Slackの有益情報まとめ。
民泊運営者・あお（青羽）がSlackを全部追いきれないため、Muse（Meta AI）が定期的にチャンネルを読み、**本当に役立つ情報だけ**をカテゴリ別に抽出してここに集約する中継リポジトリです。

Claude Code や Grok にもこの内容を伝えるため、毎回の更新はこのリポジトリにも反映します。

- スペース（見やすい管理画面）：Museアプリ内のスペース「ナイトラ有益情報まとめ」
- 対象Slack：nicetryclub.slack.com（NICE TRY CLUB）
- 初回収集：2026-11-11（対象9チャンネル・直近441投稿から108件を抽出）
- 公開範囲：Public（あお本人の許可済み。チャンネル名・カテゴリ中心で、深刻な個人情報は含めない方針）

## カテゴリ

| カテゴリ | 内容 |
|---|---|
| 商品・備品 | おすすめ家具・家電・設備、騒音センサー、寝具、暖房など |
| 補助金・融資 | 持続化補助金、東京都の補助金、融資事例、資金調達の考え方 |
| ノウハウ・運営 | トラブル対応、清掃、ゲスト対応、レビュー対策など |
| ノウハウ・集客価格 | 価格設定、PriceLabs、OTA（Airbnb / Booking.com）対策 |
| 許認可・消防・法務 | 旅館業、豊島区などの規制、消防、契約・法務 |
| AI・ツール | AI活用、業務ツール |
| イベント | オフ会、勉強会、サポート会、忘年会などの周知（日時・場所・申込付き） |
| 物件情報 | 新規リスティングの家賃・初期費用・回収目標などのベンチマーク |
| アナウンス・ルール | 運営からの連絡、面談の仕組み、コミュニティのルール |
| ポイ活・お得 | ポイントサイト、クレカ構成、マイル |

すべてのアイテムには **投稿日時・投稿者・チャンネル名・Slack原文リンク** が付いているので、原文とスレッドの続きをすぐ追えます。

## ファイル構成

- `CONTEXT.md` — 背景・対象チャンネル一覧（ID付き）・抽出基準。**Claude Code / Grok はまずこれを読む**
- `CLAUDE.md` — Claude Code向けの作業指示
- `GROK.md` — Grokへ渡すためのプロンプト文（コピペ用）
- `HANDOVER.md` — 現在の状態・直近の締切/イベント・次にやること
- `UPDATE_LOG.md` — 更新履歴
- `digest/2026-11-11_initial.md` — 初回まとめ（カテゴリ別インデックス＋直近の予定）
- `sources/shitsumon_soudan.md` — #all_2-質問-相談-参考情報- から抽出（52件）
- `sources/announce_event.md` — #all_アナウンス / #00_イベント_オンラインセッション から抽出（32件）

## 更新の仕方

1. MuseがSlackの対象チャンネルを読み直し、前回以降の新規投稿だけを抽出する
2. スペース「ナイトラ有益情報まとめ」を更新する
3. このリポジトリにも同じ内容を反映する（sourcesに追記し、digestとHANDOVER、UPDATE_LOGを更新）
4. Claude Code / Grok には「HANDOVER.mdを見て」と伝えれば文脈が伝わる
